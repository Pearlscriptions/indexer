# Code of Conduct

Pearlscriptions is infrastructure for independent verification. The repository
should be a place where contributors can discuss protocol behavior, bugs, and
operator needs clearly and respectfully.

## Expected Behavior

- Be precise and constructive.
- Assume good faith until there is clear reason not to.
- Keep disagreements focused on code, protocol behavior, tests, and docs.
- Report security-sensitive issues privately first.

## Unacceptable Behavior

- Harassment, threats, or personal attacks.
- Publishing private information or credentials.
- Pushing users toward unsafe wallet, seed, or private-key handling.
- Repeatedly derailing technical discussions.

Maintainers may edit, hide, close, or remove contributions that violate this
code. Serious or repeated violations may lead to a ban from project spaces.
